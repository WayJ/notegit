## 差距速读（Notegit 对竞品的 TOP 缺口）

1. **编辑可达性**：竞品全员在页面主操作位提供编辑/新建入口；Notegit 全站 0 链接到 edit、无站内新建（F-1/F-5 → P0-1/P0-2）。
2. **全文检索**：六个可比竞品中四个确认全文搜索（Outline/Wiki.js/BookStack/Notion），两个未确认；Notegit 仅元数据、文件名都不命中（F-3 → P0-3）。
3. **权限感知呈现**：竞品 UI 均按权限渲染操作；Notegit 读者满屏死按钮（F-2 → P0-4）。
4. **活动流**：BookStack/Notion 确认 recent activity/recents；Notegit 无任何跨页动态（F-8 → P1-3）。
5. **编辑体验**：双栏/所见即所得/自动草稿是竞品标配；Notegit 纯 textarea+手动草稿（F-7 → P1-1/P1-2）。

## Notegit 的相对优势（矩阵中不落后于竞品的行）

- git 语义呈现完整：历史/diff/恢复/分页/实时读，且「还原=新提交、历史不删」语义与 Outline 非破坏恢复同级。
- 差异化能力：`库/路径@commit` 引用码 + /cite 解析（六竞品均无对应物，直接支撑 Agent 报告引用可对应到 Web 历史）。
- 架构同构优势：与 GitLab Wiki 同属「wiki 即 git 仓库」形态，但 Notegit 以 git 为唯一真源（Wiki.js 主存储仍是数据库）。
- 轻量：零构建链、零外部 JS 依赖、页面 1.7–13.4KB（竞品无此约束优势）。
