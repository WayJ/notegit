# S14 应用壳与工作台

物化于 2026-10-15。来源：[E4](../roadmaps/2026-10-15-notegit-e4-workbench.md)。
启动依据：用户三项范围裁决（全站统一侧栏壳 / 首页原地升级为工作台 / 本轮做响应式两档）
＋ 终态方向裁决 D28（GitLab 式平台 ＋ agent 知识底座——E4 只做平台容器壳与人的工作台面）。

**开工即记录**：
1. DESIGN.md 是唯一视觉契约（AGENTS.md 强制条款）。参照稿的 oklch 蓝调色板、Inter、
   圆角/阴影数值**一律不得进入代码**——新样式零内联 hex，全部引用 token 语义；
   不引入第四种表面色；coral 仅用于主 CTA 与整幅强调卡。
2. 参照稿只贡献**产品功能设计**，其示意数字（128 篇 / 04 个库）**禁止出现**——
   Notegit 的一切数字来自真实查询面。
3. 安全不变量零回归：未认证 302 /login；无权库 = 不存在同 404 同页（D-IC-06）；
   POST 须同源 Origin；base_commit CAS 过期 409；reader POST 403；
   escapeHtml 服务端插值唯一通道；commit author 不作身份判断（DOD-03）。
4. **本 sprint 不做**：agent 读协议、机器身份模型（凭据委托落地属未来底座 epic）、
   容量压测。新增功能只做人面的工作台与检索筛选。

## Decisions (S14-x)

| id | decision | rationale |
|---|---|---|
| D1 | 波次：Wave 1 = T1（工作台查询面，新建模块）∥ T2（layout 壳＋样式）；Wave 2 = T3（工作台首页，依赖 T1+T2 合并态）。理由：`server/src/web/pages.ts` 的 `layout()` 与 `indexPage()` 同文件，壳与首页同派必然并行冲突（E1 S3/S4 教训）；查询面是全新文件，零冲突 | 写面冲突规避 ＋ WIP 2/3 |
| D2 | T2 是全站单点改造（`layout()` 一次改动波及每一页）。派工前 master 记录**现有 18 条路由与其链接基线**，验收时逐条对照，链接零缺失 | 壳改动爆炸半径最大，须有可对照基线 |
| D3 | 侧栏承载五区（查找/我的草稿/引用解析/我的凭据/管理），顶栏保留品牌 ＋ 账户菜单 ＋ 主 CTA；登录页与 403 等匿名/无导航壳**不渲染侧栏** | 参照稿 IA；账户菜单是 S12 已验收资产，登出不得回归 |
| D4 | 侧栏为**服务端渲染 + 零 JS**（当前区高亮用 `aria-current`，不用 JS 切换） | 延续 D19/D27 纯 SSR；导航不该依赖 JS |
| D5 | 工作台「最近更新」表只呈现**已发布**文档（Q-E4-2），草稿不进主表 | 跨库知识流语义纯净；草稿仅作者可见，混入会让「已发布知识」失真 |
| D6 | 两档断点只作用于**新壳与新工作台页面**＋共享表格类，不改既有页面模板的 DOM 结构（既有 `<768px` 横滚兜底保留） | 控制爆炸半径；避免 T2 与 T3 同时改同一批模板类 |

## Stories & Tasks

### Wave 1 — 工作台查询面 ∥ 应用壳（并行，写面零重叠）

- [x] **S14-T1 工作台查询面**（W03；DOD-E4-03 份额）：新建 `server/src/web/workbench/query.ts`，
  纯查询模块（只读，不写任何表——延续 D7/D18 派生纪律），三个能力：
  1. **聚合统计**（`workbenchSummary`）：可访问库数、已发布文档总数、最近一次内容更新时间。
     统计与库卡片**必须同一实时 JOIN `vault_members` 判定面**（D26）——
     无权库的文档数不计入总数，无权库不出现在任何数字里。
  2. **库卡片数据**（`vaultCards`）：当前员工有权库的 slug/name/role/文档计数/最后提交时间。
     文档计数以 `search_index` 行数或 git tree 计数为准（实现前自择并在报告说明，
     **须与统计口径同源**）；最后提交时间复用 browse/tree.ts 的派生面同语义。
  3. **路径级最近文档**（`recentDocuments`，D25）：以成功发布审计事件排序（可信身份、
     服务端时间）取最近 N 条，从各事件 `new_commit` 派生触及路径（D25：排序键必须是
     服务端审计时间，路径与作者从 Git 派生）；行含 path/title/tags/summary 片段/commit/作者/
     作者时间/vault。**作者字段命名与注释必须如实标注「Git 提交者元数据、非身份」**。
  TDD：先红后绿——成员过滤测试（无权库零出现、无权库文档数不计入总数）、
  路径派生测试、空库/无提交态、畸形 detail 降级。零新表。

- [x] **S14-T2 应用壳**（W01/W06；DOD-E4-01/07 份额）：`web/pages.ts` 的 `layout()`
  升级为「顶栏 ＋ 左侧分区导航 ＋ 内容区」三段；侧栏承载 D3 五区（当前区 `aria-current` 高亮），
  匿名/无导航壳不渲染侧栏；`assets/styles.css` 增侧栏样式 ＋ **≤1020px / ≤680px 两档断点**
  （≤1020px 收窄侧栏并隐藏次要表格列；≤680px 侧栏收成图标条、表格按列优先级隐藏）。
  **顶栏品牌与账户菜单形态保持不变**（登出不回归）；每页仍恰好一个内联 `<script>` 块，
  共享脚本引用规则不变（S12-T3 形态）。测试：壳结构断言、侧栏导航项与 active 断言、
  匿名壳无侧栏、断点规则在 CSS 中在位。
