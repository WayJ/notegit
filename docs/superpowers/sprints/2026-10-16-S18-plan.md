## Decisions (S18-x)

| id | decision | rationale |
|---|---|---|
| D1 | 波次：T1（vaults 清单+index-status ∥ T2（tree+docs）——文件所有权切分：T1 持 api-read/vaults.ts，T2 持 api-read/{tree,docs}.ts，路由注册各自模块内、routes.ts 组装点两行分置 | 写面零重叠并行（E1 S3/S4 教训规避） |
| D2 | 响应信封：成功=资源 JSON（无包裹层——与既有 /api/v1/search 风格一致）；错误=既有 `{error:{code,message}}`；ETag=`"<commit OID>"` + Cache-Control no-cache（S16 热修同构） | 字段契约稳定性优先（agent 依赖形状） |
| D3 | docs 端点字段：`{vault, path, ref, commit_oid, frontmatter:{title,tags,...}|null, body, body_raw, size_bytes, fetched_at}`——body=frontmatter 剥离后正文、body_raw=原文（双字段给全，不预设消费方）；仅 `.md`（与页面族同判——其余类型 v1 不提供，如实 415/404） | D36 延伸：原始 Markdown ＋ 双字段 |
| D4 | tree 端点：`{vault, ref, commit_oid, entries:[{path,type,size}], truncated}`——扁平路径数组（agent 自行构树）；上限 1000 条 + truncated 如实标注（Q-E6-1 v1 形态） | 最小稳定面 |
| D5 | 契约建议稿随任务：docs/s18/api-amendments.md（draft-first，两任务各持一节） | D12–D14 先例 |
