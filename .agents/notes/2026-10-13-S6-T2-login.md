## 选型记录（decisions）

1. **登录形态 = username + token（粘贴式）**。api.md 既有端点盘点：`POST /api/v1/credentials` 创建 token（明文仅一次，需已认证载体——Web UI 创建后粘贴给 CLI）；`POST /api/v1/auth/login` 是 Web 会话（username+password→Cookie），**没有**面向 CLI 的一次性引导码端点（`auth/bootstrap` 仅为实例初始化）→ 缺口见下。校验令牌用 `GET /api/v1/credentials` + `Authorization: Bearer`（200=有效；401 按 E-AUTH-001..004 映射无效/过期/撤销/停用可读错误）。
2. **凭据存储 = 自带 helper 子命令（`notegit credential get|store|erase`）+ 0600 文件**（`~/.config/notegit/credentials`，XDG 惯例，`NOTEGIT_CREDENTIALS_FILE` 可覆盖），不用 OS keyring 原生依赖：keytar 已弃维、secret-tool 在 headless Linux 缺失，任何原生依赖破坏 T1 的纯 JS 分发。文件即 breakdown「凭据文件权限受限」的落点（0600 文件、0700 目录，写后显式 chmod 收紧）。
3. **helper 注册 = 按 host 作用域 + 空值重置**：`credential.<proto>://<host>.helper` 两值序列 `["", "!<CLI 绝对路径> credential"]`（gh auth 同款作用域做法 + git 标准链重置语义）。空值重置使本 CLI 是该 server 凭据的**唯一**来源：token 不透传给 osxkeychain/libsecret（不产生第二份明文副本），且规避 headless/sandbox 环境 keychain 阻塞（本 worktree 实测：Apple Git 系统配置注入 osxkeychain，其 `get`/`store` 在无 GUI 通道时可永久挂起，且 `GIT_CONFIG_SYSTEM=/dev/null` 对 Apple Git 无效、需 `GIT_CONFIG_NOSYSTEM=1`）。不影响用户其他 host 的 helper 链。
4. **ls-remote 验证 = 本地模拟 git serve**（非真实服务实例）：Node 包裹真实 `git http-backend` CGI（S1 spike route B 验证过的模式，与生产同一 Git 栈）+ Basic/Bearer 双入口鉴权（`cli/test-support/mock-server.ts`）。真实服务实例需要 pepper/DB/管理员初始化链路，对 CLI 单测过重。集成测试断言：登录后 `git ls-remote`/`git clone` 在 `GIT_TERMINAL_PROMPT=0` + 无 askpass 下免交互成功；换错 token 后被 401 拒（证明真鉴权）。
5. **token 输入面 = 隐藏交互输入或 `NOTEGIT_TOKEN` 环境变量，绝不走 argv**（`--token` 显式拒绝，防 `ps` 进程列表泄漏）；stdout 只出现掩码 `ngt_ab…wxyz`（api.md §4 `display_hint` 同款）。TTY 下抑制回显（凭据不进终端回滚缓冲）。
6. **凭据键 = protocol+host（含端口）**：server URL 路径忽略（警告提示），假设服务端部署在 host 根（架构 §10 单容器；无路径前缀部署的证据）。Basic 用户名按 api.md §1 任意、仅作标识存储。
7. **退出码**：0 成功；1 = 令牌形态不符/服务端拒绝（四状态）/不可达/stdin EOF 未提供；2 = 用法错误（缺 server、坏 URL、未知旗标、`--token`、多余参数）。

## honest-gaps（如实标注）

- **一次性引导码端点不存在**（brief 预授权「无则记录缺口」）：api.md 无 CLI 引导码/设备码端点；`auth/bootstrap` 仅实例初始化。当前 CLI 必须从 Web UI「查看访问凭据」创建后粘贴。若产品要求免 Web 创建（如 `notegit login` 免粘贴流程），需 epic 级新端点（建议形态：短时效单次引导码 → 服务端换发 ngt_ token）。
- **无 whoami 端点**：用户名不经服务端核验（Basic 用户名本就任意）；登录后显示的 `<user>@<host>` 中 user 是本地输入。`GET /api/v1/credentials` 只回凭据列表不含账号名。
- **`notegit logout` 未实现**（不在本任务 Change 面）：撤销 = Web 端 DELETE /api/v1/credentials/{id}；本地清理可手动 `notegit credential erase`。建议随 T8 文档或后续任务补 CLI 入口。
- **logout/多账号**：同 host 多 username 共存（store 语义），git get 无 username 约束时取首条；单员工单 server 的第一版假设，未做切换命令。
- **Apple Git 特性**：`GIT_CONFIG_SYSTEM=/dev/null` 不生效（仍读 /Library/Developer/CommandLineTools 系统配置）；测试用 `GIT_CONFIG_NOSYSTEM=1` 隔离。生产用户不受影响（空值重置在真实系统配置在场时同样接管本 host 链，已实测验证）。
