# S4-T7 base commit 冲突保护

## background
breakdown §2.3 S4-T7 行；S3-T7 发布组件（CAS 唯一机制）与 S4-T6 草稿状态流转（submitEditForm 挂点）已就绪。基线 553+106（rebase 到 sprint/S4 @ 4ff96f6 ⊇ T6）。完成标准：Web×Git 并发与两次网页提交两冲突场景（后提交方被拒、先前提交不覆盖、冲突草稿完整保留）+ 成功路径与直接 push 等价。

## decisions
- **submissions 端点落 `server/src/web/edit/submissions.ts`（FastifyPluginAsync 封装插件）**：路径 /api/v1/vaults/{slug}/submissions（api.md §8.2；编辑页 SUBMIT_URL 自 T3 定形即指向此）。封装插件是必须的——`addContentTypeParser('application/json')` 只能在插件作用域覆盖（bodyLimit 护栏同 drafts 形态），直接挂根实例会全局改变其余 /api/v1 JSON 端点解析。组装点 web/routes.ts append 一块注册（D5「冲突保护」明列预期 append；gate 经 WebRoutesOptions 透传给组件层最后一道）。
- **submit 面抽 `submitComposedChanges`（submit.ts 内单点保持 T6 挂点）**：端点请求体是已组装的 §8.2 changes（编辑页 composeDoc 在页内完成），无法走 fields+body 形态的 submitEditForm——抽出「组装完成变更集 → publishWebSubmit → published 后逐路径 markCommitted」核心，submitEditForm 委托之（行为不变，T6 测试原绿）。草稿流转挂点不因入口增加而分叉。
- **409 信封 details={base_commit, current_head}**：组件 RejectedResult 不携带实际 ref OID（reason 文本内嵌不可靠解析），端点响应时点自行 rev-parse 呈现（pipeline.ts 不在本任务 ownership，零改动）。update-ref CAS 竞态同映射 409（api.md §1 重试幂等语义：HEAD 已前进即 409，不静默重复发布）。
- **base_commit 前置 400（非 SHA 形状 / 库外 OID）**：T6 lesson「candidate 阶段先拒库外 OID」——API 语义上属请求形态错误（E-RES-004），前置判定给准确状态码；组件链仍全量复核（纵深非替代）。
- **预填基线 = 打开时 HEAD（非草稿旧基线）**：架构 §6 字面「打开编辑器时记录 base commit」；T6 移交「回填时须同时呈现 base_commit 旧值」解读为**呈现**（对照信息）而非**采用**——若采用旧基线，过时草稿将永久 409 死锁；若静默换新基线，则同一文件并发改动被无声覆盖。取舍：内容回填草稿、CAS 基线取打开时 HEAD、旧基线+保存时间如实呈现；基线不一致标注「分支已前进」提示核对——409 拒绝 + 刷新重开 = 用户显式跨越冲突点，不静默覆盖语义完整且流程可终止（409→刷新→201 闭环已测）。
- **授权前置 authorize write（非 read）**：§8.2 明列 editor+——与 drafts PUT 同形（reader 403 E-AUTHZ-001、非成员/未知库 404 同体）；组件 authorization→404 / branch-rules→403 / execution-point 按因 403·404·503（reason 子串判维护/撤权/配置缺失——同 rename 既有形态）。

## lessons
- 页内 409 脚本文案含「分支已前进」——「基线一致时无过时提示」断言必须用 note 专属形态 `<strong>分支已前进</strong>`（否则页内脚本永远命中）。
- 维护 503 测试在端点实现前即绿：app 级 maintenanceGuard 先于路由生效（任务书「闸门缝已就位」的印证）——该测试是护栏不是 RED 驱动；RED 驱动 = 两冲突场景（404!==409 起步）。
- 等价断言用 **tree OID 全等**（`rev-parse HEAD^{tree}`）而非 commit OID：两入口 identity/时间戳不同 commit 必不同，tree 是内容等价的准确锚点；辅以 ls-tree -r 全等与「父=基线」快进断言。
- inject 对象 payload 自动 JSON 序列化并丢弃 undefined 键——message 可选传递无需条件展开。
